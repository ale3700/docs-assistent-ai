# Projetos

## Assistente de Atendimento com RAG
Chatbot para suporte ao cliente que responde com base em uma base de conhecimento interna.
Stack: Python, LangChain, ChromaDB, FastAPI. Reduziu o tempo médio de resposta em 40%.

## Dashboard de Vendas
Painel interativo em Streamlit e Pandas que consolida dados de vendas de várias regiões
e destaca tendências sazonais. Stack: Python, Pandas, Plotly, PostgreSQL.

## API de Recomendação de Filmes
Serviço REST que recomenda filmes por similaridade de embeddings.
Stack: FastAPI, sentence-transformers, FAISS, Docker.
